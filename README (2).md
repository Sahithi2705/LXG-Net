# Dataset files

This folder contains the CSV files supplied with the LXG-Net project:

- `neonatal_low_burden.csv`
- `neonatal_moderate_burden.csv`
- `neonatal_high_burden.csv`
- `realistic_nicu_sensor_data.csv`
- `nicu_combined_dataset.csv`

The files represent project/constructed data for proof-of-concept experimentation. Inspect the notebook to see how the files are loaded, joined, cleaned, and transformed. Do not assume that every CSV is an independent patient cohort or that the records represent real clinical observations.

Before publishing the repository publicly, verify the source and redistribution permission for every dataset. If permission is unclear, omit the raw CSVs from the public repository and provide instructions for obtaining or regenerating them instead.
